# 客户 API 申请与凭证提供清单

## 富途

- 富途账号，可登录 FutuOpenD。
- OpenAPI 权限已开通。
- 模拟交易已在富途 App 开通。
- FutuOpenD 所在机器、端口和网络访问方式。
- 实盘上线前：交易解锁流程、账户市场权限、可交易币种确认。

## 老虎

- `tiger_id`。
- RSA 私钥文件，由客户安全提供。
- Paper 模拟账户号，通常为 17 位数字。
- 实盘账户号，上线前提供。
- 账户类型确认：Global / Standard / Margin。

## 市场与风控确认

- 是否纳入策略一空头交易。
- 美股账户是否满足 PDT 规则。
- 港股做空名单与报升规则如何处理。
- 单日最大亏损、单笔仓位、最大同时持仓是否沿用当前方案默认值。
- 背离、柱体缩短、站稳/破位均线的精确定义是否授权开发方在回测阶段确定。

## 交付前禁止事项

- 不把真实账号、私钥、解锁密码写入代码或文档。
- 不在未完成模拟盘验证前开启实盘自动交易。
- 不绕过 PDT、做空、停牌、除权除息和重大公告过滤。
