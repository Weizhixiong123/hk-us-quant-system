# 引擎热重载 — 单租户网页自助 设计文档

> 日期：2026-06-25
> 范围：让单租户客户在网页上完成全部运维(启停 / 切运行模式 / 填券商凭证 / 调策略参数),点「保存并应用」后引擎**进程内热重载**即时生效,无需 SSH 重启服务器。
> 前置:已有实盘配置页 `LiveSettingsPanel.vue` + `settings.json` + runtime 的干净 `start()`/`stop()`。

---

## 1. 背景与问题

当前 runtime 在后端启动时由 `build_live_runtime_from_env` 构建一次(`main.py` lifespan)。客户在配置页改了 `enabled` / 运行模式 / 券商 / 凭证 并保存到 `settings.json` 后,**运行中的进程不会重建引擎、不会换网关**——必须人工 SSH 重启 uvicorn 才生效。给非技术客户用时,这不可接受。

## 2. 决策(已与用户确认 2026-06-25)

- **单租户**:一套系统服务一个客户、用客户自己的券商账户。不做多租户/SaaS。
- **完整自助**:启停 / 切模式 / 券商凭证 / 策略参数 全在网页完成(输入部分已具备:`LiveSettingsPanel` + `PUT /strategies/{id}/params`)。
- **方案**:进程内热重载(非进程重启,无服务中断)。
- **触发**:显式「保存并应用」按钮(切实盘是真钱重操作,显式确认更安全)。
- **本期不做认证**:登录以后单独做;**上公网前必须补**。

## 3. 架构与改动

### 3.1 RuntimeManager(新增)

封装引擎生命周期,持有**跨重载保留**的 `live_state` 与 `params`(dashboard 始终读同一个),内部维护"当前 runtime"。

```
async start():   首次启动(lifespan startup)
async stop():    关闭(lifespan shutdown)
async reload():
  1. await 当前 runtime.stop()        # 已有:cancel 循环 + gateway.close()
  2. build_live_runtime_from_env(live_state, params)   # 读最新 settings 重建
  3. await new_runtime.start()        # enabled 决定是否连网关
  4. 替换当前 runtime 引用
  - asyncio.Lock 串行化,防并发重载
  - 失败:捕获异常 → 引擎停在"已停止"安全态(不留半启动)→ 记日志 → 向上返回错误
```

`main.py` 改为持有 `RuntimeManager`;dashboard / health 通过它取当前 runtime。

### 3.2 启停统一靠 reload

不另设多按钮。启停 / 切模式 / 换券商 / 改凭证 **均 = 改 settings + reload**:

- 启动引擎 = `enabled:true` + reload(连网关)
- 停止引擎 = `enabled:false` + reload(`start()` 直接 return,空转 = 停)
- 切 干跑/模拟盘/实盘 = 改 mode/broker + reload(重建对应网关)

### 3.3 API

- **新增** `POST /api/runtime/reload` → `RuntimeManager.reload()`;返回重载后真实状态(`enabled` / `mode` / `broker` / `connected` / `error`)。
- 保留 `PUT /api/live-settings`(纯保存配置)。
- 前端「保存并应用」= `PUT /live-settings` 成功 → `POST /runtime/reload`。

### 3.4 配置页 UX

- 实盘配置页加「**保存并应用**」按钮。
- 状态机:应用中(loading)→ 成功(显示新状态)/ 失败(显示错误原因)。
- 「运行状态」卡 + `/api/health` 反映引擎当前 `enabled` / `mode` / `connected`。

## 4. 失败处理

- reload 重建或 `start()` 失败(凭证错 / 网关连不上 / vnpy 缺失):捕获 → 引擎置于"**已停止**"安全态(不半启动、不乱交易)→ API 返回错误信息 → 前端显示「应用失败:<原因>」。
- **不回滚**到旧配置。理由:停止是最安全的失败态;回滚旧实盘配置反而可能更危险。客户改正配置后重新「保存并应用」。

## 5. 测试

- **远程 TDD**(`DryRunGateway`,纯逻辑,远程可跑):
  - reload 后引擎使用新配置;旧 runtime 已 `stop`;
  - `enabled` 切换正确控制启停;
  - 并发 reload 被 Lock 串行;
  - reload 失败 → 引擎置停止态 + 返回错误。
- **本地验证**(vnpy,远程装不了):真连网关 stop→重建→start 干净(断连重连、无残留订阅/线程);干跑→模拟盘→实盘 各模式重载正确。

## 6. 边界 / YAGNI

- 本期不做认证(登录后续单独做,**上公网前必须**)。
- 不做配置回滚。
- 不做分策略独立启停(整机 reload)。
- 切实盘的真钱确认沿用现有 settings 校验(`REAL`/`live` 需确认令牌)。
- 多租户、凭证加密存储:不在本期。

## 7. 成功标准

- 客户在网页改配置(启停 / 切模式 / 凭证 / 参数)+ 点「保存并应用」→ 引擎**进程内重载、即时生效**,全程不碰服务器命令行。
- reload 失败时引擎**安全停止**并在网页显示原因。
- 远程 reload 逻辑测试全绿;本地真连网关重载验证通过。
