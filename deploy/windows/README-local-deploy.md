# 港美股双策略量化系统 Windows 本地部署说明

## 一、客户电脑准备

1. Windows 10/11。
2. 如果使用富途，先安装并登录 Futu OpenD。
3. 如果使用老虎，提前准备 Tiger ID、账户号、License、私钥文件。
4. 首次运行建议先使用“干跑”或“模拟盘”，确认一天完整流程后再切实盘。

## 二、启动系统

1. 解压 `hk-us-quant-client.zip`。
2. 双击 `start.bat`。
3. 浏览器会自动打开：

```text
http://127.0.0.1:8000
```

如果浏览器没有自动打开，手动复制上面的地址访问即可。

## 三、富途 OpenD 登录

1. 打开 `FutuOpenD.exe`。
2. 使用客户自己的牛牛号、邮箱或手机号登录。
3. 完成手机验证码或二次验证。
4. 保持 OpenD 窗口运行。
5. 在系统的“实盘配置”页面填写：

```text
Host: 127.0.0.1
Port: 11111
交易平台: 富途
运行模式: 干跑 / 模拟盘 / 实盘
```

富途账号密码只在客户电脑的 OpenD 中输入，不要填写到本系统，也不要发送给开发人员。

## 四、老虎配置

进入“实盘配置”页面，选择“老虎”，填写客户自己的：

```text
Tiger ID
Account
License
Private Key Path
Public Key Path
Environment: sandbox / live
```

老虎私钥建议放在客户电脑本地固定目录，例如：

```text
C:\quant-keys\tiger_private_key.pem
```

## 五、停止系统

如果 `start.bat` 窗口还在，直接关闭窗口即可。

也可以双击：

```text
stop.bat
```

它会停止本机 `8000` 端口上的系统服务。

## 六、运行时修复

如果启动时报 Python runtime 相关错误，双击：

```text
repair-runtime.bat
```

该脚本会在客户电脑重新创建 `runtime` 并安装后端依赖。执行这个脚本要求客户电脑已安装 Python 3.11 或更高版本。

## 七、数据保存位置

本地配置、订单、成交和日志数据保存在解压目录：

```text
data\
```

重新打包或升级系统前，建议先备份这个目录。

## 八、安全注意事项

1. 本地服务默认只监听 `127.0.0.1`，不要改成公网地址。
2. 不要把富途 OpenD 暴露到公网。
3. 不要把老虎私钥、富途账号密码发送给开发人员。
4. 实盘前必须先跑模拟盘，确认连接、行情、订单、成交、风控日志都正常。
5. 实盘模式需要客户本人在页面输入确认短语后再保存。
